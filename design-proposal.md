# Design Proposal
## Catholic Diocese of Tombura-Yambio Website

**Date:** October 7, 2026
**Status:** PROPOSAL - Awaiting Diocesan Approval

---

## Executive Summary

This design proposal outlines the visual direction for the new Catholic Diocese of Tombura-Yambio website. The design will be:

- **Catholic and dignified** - Reflecting the sacred nature of the Church
- **Welcoming and pastoral** - Inviting to all visitors
- **African and contextual** - Honoring South Sudanese culture
- **Modern and professional** - Contemporary while respectful of tradition
- **Accessible and usable** - Easy for all users to navigate
- **Fast and responsive** - Optimized for all devices and connection speeds

---

## Design Philosophy

### Core Principles

1. **Dignity Over Flash**
   - Avoid excessive animations and effects
   - Use generous whitespace
   - Prioritize clarity over novelty
   - Respect the sacred nature of the content

2. **Community-Centered**
   - Feature real people and places
   - Show the diversity of the diocese
   - Highlight community activities
   - Emphasize service and ministry

3. **Contextual Authenticity**
   - Draw inspiration from South Sudanese culture
   - Use local imagery where possible
   - Incorporate African artistic elements subtly
   - Reflect the local landscape and environment

4. **Digital Accessibility**
   - Design for slow internet connections
   - Optimize for mobile devices
   - Ensure keyboard accessibility
   - Maintain high contrast ratios

5. **Catholic Identity**
   - Use liturgical colors thoughtfully
   - Incorporate sacred art respectfully
   - Maintain ecclesiastical dignity
   - Reference Catholic symbolism appropriately

## Visual Identity

### Color Palette

#### Primary Colors
**Deep Green (Growth, Life, Hope)**
- Primary: #1B5E20 (Forest Green)
- Secondary: #2E7D32 (Medium Green)
- Accent: #4CAF50 (Light Green)

**Inspiration:** South Sudan's lush landscape, growth, hope, and the liturgical color for ordinary time

#### Secondary Colors
**Gold (Divinity, Majesty, Celebration)**
- Primary: #FFB300 (Gold)
- Secondary: #FFCA28 (Light Gold)
- Accent: #FFD54F (Pale Gold)

**Inspiration:** Divine light, celebration, liturgical vestments

**White (Purity, Light, Peace)**
- Primary: #FFFFFF (Pure White)
- Secondary: #F5F5F5 (Off-white)
- Accent: #E0E0E0 (Light Gray)

**Inspiration:** Purity, peace, light

#### Accent Colors
**Red (Martyrdom, Holy Spirit, Love)**
- #C62828 (Deep Red)
- Use sparingly for emphasis, feast days, important calls to action

**Blue (Mary, Heaven, Truth)**
- #1565C0 (Royal Blue)
- Use for Mary-related content, trust, stability

**Earth Tones (Land, Humility, Work)**
- #795548 (Brown)
- #8D6E63 (Light Brown)
- Use for agricultural content, land references

#### Neutral Grays
- Text: #212121 (Near black)
- Secondary text: #616161 (Dark gray)
- Borders: #BDBDBD (Medium gray)
- Backgrounds: #FAFAFA (Very light gray)

### Typography

#### Primary Font (Headings)
**Source:** Google Fonts
**Font:** Merriweather or Playfair Display
**Style:** Serif
**Why:** Traditional, dignified, readable, Catholic publications commonly use serif

**Weights:**
- Light (300)
- Regular (400)
- Bold (700)

#### Secondary Font (Body)
**Source:** Google Fonts
**Font:** Inter or Open Sans
**Style:** Sans-serif
**Why:** Modern, highly readable, excellent for screen, good legibility at small sizes

**Weights:**
- Regular (400)
- Medium (500)
- Bold (700)

#### Typography Scale
- H1: 2.5rem (40px) - Page titles
- H2: 2rem (32px) - Section titles
- H3: 1.5rem (24px) - Subsection titles
- H4: 1.25rem (20px) - Card titles
- Body: 1rem (16px) - Base text
- Small: 0.875rem (14px) - Captions, metadata
- X-Small: 0.75rem (12px) - Fine print

#### Line Height
- Headings: 1.2
- Body: 1.6
- Captions: 1.4

### Imagery Style

#### Photography Guidelines
1. **Authentic Over Stock**
   - Prioritize real photos of diocesan activities
   - Show actual people, places, and events
   - Avoid generic stock imagery
   - When stock is necessary, choose diverse, African contexts

2. **Dignified Portraiture**
   - Respectful photography of clergy and religious
   - Appropriate liturgical contexts
   - Natural lighting preferred
   - Avoid overly posed or artificial images

3. **Community Focus**
   - Show community activities
   - Include diverse groups (youth, elderly, families)
   - Capture service and ministry moments
   - Include liturgical celebrations

4. **Landscape and Context**
   - South Sudanese landscapes
   - Parish churches and buildings
   - Agricultural projects
   - Local environments

#### Image Treatment
- Subtle warm tone (slight increase in temperature)
- Moderate contrast
- No heavy filters
- Consistent aspect ratios within sections
- Responsive cropping for different breakpoints

#### Iconography
**Style:** Line icons or simple filled icons
**Source:** Custom SVG icons or Iconify (specific icon sets)
**Characteristics:**
- Clean, modern
- Culturally appropriate
- Religiously respectful
- Consistent stroke width (2px)

**Icon Categories Needed:**
- Navigation (menu, search, close)
- Actions (download, share, print)
- Content (news, events, sermons, documents)
- Contact (phone, email, location, map)
- Social (Facebook, YouTube, etc.)
- Religious (cross, bible, church, chalice - use respectfully)

## Responsive Design

### Breakpoints

**Mobile First Approach:**
- Base styles: Mobile (< 768px)
- Tablet: 768px - 1024px
- Desktop: > 1024px
- Large Desktop: > 1440px

### Mobile Considerations

**Navigation:**
- Hamburger menu
- Full-screen overlay
- Large touch targets (44px minimum)
- Back buttons for navigation

**Content:**
- Single column layout
- Stacked cards
- Readable text (16px minimum)
- Optimized images
- Reduced animations

**Performance:**
- Lazy load images
- Minimal JavaScript
- Optimized fonts
- Code splitting

**Touch:**
- Adequate spacing between links
- No hover-dependent interactions
- Tap feedback
- Swipe gestures (if applicable)

### Tablet Considerations

- Two-column layouts where appropriate
- Horizontal navigation if space allows
- Larger touch targets
- Optimized table layouts

### Desktop Considerations

- Multi-column layouts
- Hover states
- Richer interactions
- Larger images
- More content visible above fold

## Accessibility

### Color Contrast
- All text: WCAG AA (4.5:1 minimum)
- Large text: WCAG AA (3:1 minimum)
- Interactive elements: WCAG AAA (7:1 preferred)

### Keyboard Navigation
- All interactive elements keyboard accessible
- Visible focus indicators
- Logical tab order
- Skip navigation link
- No keyboard traps

### Screen Reader Support
- Semantic HTML
- ARIA labels where needed
- Alt text for images
- Proper heading hierarchy
- Form labels properly associated

### Other Accessibility
- Resizable text (up to 200%)
- No content that flashes more than 3 times per second
- Captions for video (if applicable)
- Transcripts for audio (if applicable)
- Error messages clearly associated with form fields

---

## Performance Considerations

### Image Optimization
- WebP format with fallback to JPEG
- Responsive images (srcset)
- Lazy loading below fold
- Appropriate compression
- Progressive JPEGs

### Font Loading
- Font display: swap (prevents FOUT)
- Subset fonts (only needed characters)
- Preload critical fonts
- System font fallback

### Code Optimization
- Minified CSS and JavaScript
- Code splitting
- Tree shaking
- Remove unused code
- Critical CSS inline

### Caching
- Browser caching headers
- Service worker for offline support
- CDN for static assets
- Static generation where possible

---

## Animation and Micro-interactions

### Principles
- Subtle and purposeful
- Respectful of content
- Not distracting
- Accessible (respect prefers-reduced-motion)

### Examples
- Button hover: Background color transition (200ms)
- Card hover: Slight lift with shadow (300ms)
- Menu: Slide-in animation (300ms)
- Page load: Fade-in (500ms)
- Scroll: Smooth scroll to anchors

### Avoid
- Excessive animations
- Auto-playing videos
- Parallax effects (performance)
- Unnecessary decorative animations
